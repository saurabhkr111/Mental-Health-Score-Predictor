# Mental-Health-Score-Predictor


An end-to-end Machine Learning application that estimates mental health scores based on digital habits, lifestyle, academic activities, and behavioral factors.

## Live Demo

[**Try Mental Health Score Predictor**](https://mental-health-score-predictor-2-h6jt.onrender.com/)

## Overview

This project uses Machine Learning to analyze user-provided information and generate estimated mental health scores. It demonstrates the practical application of data science, model development, and API integration.


## Key Features

- Mental health score prediction.
- Digital habits and lifestyle analysis.
- REST API integration.
- Input validatio
- Interactive user interface.
- Real-time predictions.

## Tech Stack

- **Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **Backend:** FastAPI
- **API Server:** Uvicorn
- **Validation:** Pydantic
- **Frontend:** HTML, CSS, JavaScript

## Disclaimer

This application is developed for educational purposes. Predictions are estimates and should not be considered medical diagnoses or a substitute for professional mental health advice.
